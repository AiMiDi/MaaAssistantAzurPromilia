# 蓝色星原助手 · 开发版

设置官方启动器路径后，助手可启动游戏、确认资源更新并等待进入。首次登录和验证码需手动完成。

**家园日常**：收获（含牧场）→ 读取餐桌缺口、扣除已有饼干 → 仅制作所需小麦饼 → 补餐。小麦不足则报告缺口，不整批补种；保留已有制作队列。

**一键领取 · 已适配奖励**：邮件、签到、日常、周常、小小侠客养成记、星之旅录、成就积分。列表按默认排序检查，领取后重新识别，另行检查阶段奖励。也可单独勾选各奖励任务，避免与组合重复选择。

旅录190积分奖励、签到、活动任务、日常20活跃宝箱已有实领记录。周常和成就目前验证了未达标跳过分支，达标领取仍待实测；35任务最终角色奖励和其他活动详情尚未接入。

支持中文16:9画面，本机实测1920×1080，使用720p归一化识别。其他16:9分辨率尚未逐一实测；未知页面或识别失败时停止并保留页面供排查。

运行时请勿同时操作游戏。默认恢复并置顶游戏，任务结束后恢复原置顶状态，可在全局设置中关闭。
