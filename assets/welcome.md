# 蓝色星原助手 · 开发版

先启动 bilibili PC 版游戏并进入主界面，再在助手中选择游戏窗口。

推荐只勾选 **家园日常**：一键收获 → 从低成本候选中制作食物 → 收取成品 → 一键补餐。
候选包括小份波波饼（小麦×4，饱腹+25）和惊奇爆谷（玉米×6，饱腹+10），可以分别开关、改变优先顺序，选择最大数量/1份/跳过。餐桌一键添加会使用背包里的可用料理。

当前支持中文界面、16:9 画面；本机实测 1920×1080。1280×720、2560×1440 等同等比例分辨率使用 720p 归一化识别，尚未逐一实测；其他比例会停止操作。

运行时不要操作游戏鼠标或遮挡游戏。助手采用前台输入，游戏请勿最小化。

已经验证邮件、签到单步领取和家园收获/补餐/烹饪。完整任务仍在联调，失败时会保留页面并输出日志。

日常活跃度宝箱还在调试，暂不放入默认任务。不会执行战斗、抽卡、充值、购买或取消现有生产队列。
