# 奖励领取

基于 CBT3 中文 PC 界面，2026-09-23 在本机 1920×1080 下验证，识别归一化至 1280×720。

## 使用

在助手中勾选 **一键领取 · 已适配奖励**，或选择需要的单项。组合包含邮件、签到、日常、周常、小小侠客养成记、星之旅录及成就积分阶段奖励。组合与对应单项不必重复勾选；家园任务仍可独立使用。

## 列表和阶段奖励

- 日常、周常及旅录利用游戏的默认排序：顶部可领取项优先，遇到未完成/已领取便停止下翻。领取一次后读取新画面，允许一次点击批量领取并重新排序。
- 旅录仅星轨分类有章节箭头，其他分类直接检查首行；不把章节箭头坐标用于普通任务卡片。
- 旅录进入时先检查阶段奖励，每章任务处理后再检查。没有任务可领，也仍检查底部积分档位。50/120/190/220/260/300 按积分及已领取勾选标记判断，领取后确认奖励弹窗和勾选标记。
- 成就只检查左下角积分阶段奖励。`+135/200` 表示当前135、下一档200；未达标跳过，不点击成就分类列表。
- 页面未知、计数无法读取、点击后没有状态变化时停止并报告，不重复点击未确认的领取。

组合任务 `ClaimRewards` 已完成一次全流程真机复跑：各单项均无新增奖励时正常跳过，成就135/200不点击，最终返回菜单。121项单元测试及Pipeline/界面Schema校验通过。
