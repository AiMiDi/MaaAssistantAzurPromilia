## 教程里对流程有用的说明

- [固定派驻](https://ap-cbt3.csxylic.com/guide/8103/)说明指定建筑的奇波会专注于该建筑，并在管理面板显示锁定状态。后续诊断要区分主动锁定与空岗，不能自动打乱。
- [行情说明](https://ap-cbt3.csxylic.com/guide/12402/)把行商手记作为当日价格入口。参考对话提到今明两日趋势，但本次读取的 Wiki 摘要只明确当日；明日预测字段留待游戏验证。
- [出售与出货](https://ap-cbt3.csxylic.com/guide/12403/)区分提前售出与等待出货的奖励。实际刷新时刻、提前卖出代价及奖励需要当前界面确认，暂不写定时出售任务。
- [孵化桩](https://ap-cbt3.csxylic.com/guide/5201/)可作为孵蛋入口参考，尚未证明本账号有哪些蛋、槽位和完成项目。
- [心得点获取](https://ap-cbt3.csxylic.com/guide/8401/)与[心得使用](https://ap-cbt3.csxylic.com/guide/8402/)支持把解锁作为目标的前置检查；本轮只准备资料。

## 数据解释与待核对事项

1. **版本冲突**：参考对话称饱腹值已移除；Wiki 的[自动种植教程](https://ap-cbt3.csxylic.com/guide/3503/)仍提到相关条件，本项目也有补餐真机记录。另有角色饱腹教程，不能混为同一机制。以当前账号画面补证后再决定默认行为。
2. **ID 与数量**：[伐木场资料](https://ap-cbt3.csxylic.com/home/collection/11101/)的“奇波容量”显示 `2001`，暂按未解释字段保留，不能读成可放 2001 只奇波。
3. **种植时长和产出**：[普通金麦种子](https://ap-cbt3.csxylic.com/home/seed/1/)显示小数分钟、需浇水数值及多组产出／进阶行。未核对浇水与效率影响前，不用这些字段推算本账号准确收获时间或期望收益。
4. **名称与品质**：同名或相近名称不等于同一物品；以物品 ID 区分，保留 UI 别名映射。装备产出 ID 缺失时不根据名称猜 ID。
5. **动态与静态价格**：配方的静态直接出售和订单价格可作参考，不能替代行商实时报价；保留材料优先于交易建议。
6. **解锁及加成**：科技、声望、生产效率和随机返还随账号变化。资料中的基础值只用于预览，执行前需要账号检查。
7. **覆盖范围**：86 个配方不是全游戏可制作物品。未收录材料只能标记缺口或待查，不能推断没有获取途径。
